TechKnowLogy | Full-Stack Web Application
Co-developed TechKnowLogy, an interactive e-learning platform built with a complete client-server 
separation. I engineered a robust backend REST API using Express.js and managed the database architecture 
with MongoDB and Mongoose (leveraging document relations). On the frontend, I implemented a responsive, 
dynamically rendered UI featuring secure user authentication, advanced search and filtering 
functionalities, and seamless data fetching. Through this project, I successfully delivered a 
comprehensive, end-to-end educational tool while collaborating effectively within a technical team.
